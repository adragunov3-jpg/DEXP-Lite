# DEXP Lite 0.2 — красивая лёгкая оболочка для DEXP U43G9000CG

**Для устройства:** DEXP U43G9000C/G (на фотографии написано U43G9000CG), Яндекс ТВ / Android 9, ориентировочно шасси CV9632-M42. Сверяйте версию Android в настройках телевизора: разные прошивки могут отличаться.

## Что готово

- Тёмный интерфейс в графитово-фиолетовых оттенках, крупные плитки приложений с оригинальными иконками.
- Работа стрелками и OK на пульте, отдельный раздел избранного, каталог всех доступных приложений.
- **Удерживайте OK** на плитке для добавления/удаления из избранного (если прошивка доставляет событие долгого нажатия).
- Дата и время (обновление раз в минуту, только пока лаунчер открыт).
- Кнопка перехода в системные настройки.
- Нет рекламы, разрешения на интернет, запросов в облако, сторонних библиотек, фоновых служб и тяжёлых анимаций.
- Скрипт для диагностики установленной прошивки и просмотра списка пакетов. Опционально можно вручную отключить **только два** известных необязательных пакета; сохраняется журнал восстановления.

## Важные ограничения

- **Это приложение-лаунчер, не новая ОС/прошивка.** Само по себе оно не ускоряет процессор, не удаляет Яндекс ТВ и не отключает службы системы.
- YaOS может игнорировать выбор стороннего приложения в качестве Home. Пульт и кнопка Home сохраняются под контролем прошивки. Чтобы заменить Home навсегда, сперва нужно проверить именно вашу сборку.
- Нельзя гарантировать прирост скорости без реальных замеров до/после на телевизоре.
- Переход к HDMI, тюнеру, Алисе и фирменным настройкам остаётся через штатные средства телевизора. **Не отключайте `com.yandex.tv.home`, `com.yandex.tv.services.platform`, `com.yandex.tv.services`, `com.yandex.tv.live`, `com.yandex.tv.input.efir`, `ru.yandex.androidkeyboard.tv`.**
- Проект **не был собран в APK и не был проверен на физическом телевизоре** в среде автора. Исходники можно собрать локально или с помощью приложенного GitHub Actions. Первая установка только как обычного приложения.

## Как получить APK (Windows / macOS / Linux)

1. Установите **Android Studio** с JDK 17 и Android SDK Platform 35.
2. Распакуйте ZIP, откройте в Android Studio папку `DEXP_Lite_Project`.
3. Дождитесь Gradle Sync (при первом запуске интернет нужен для сборки).
4. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Файл: `app/build/outputs/apk/debug/app-debug.apk`.

**Вариант без Android Studio:** загрузите содержимое `DEXP_Lite_Project` в свой репозиторий GitHub, откройте **Actions → Build DEXP Lite APK → Run workflow**, затем скачайте артефакт `dexp-lite-0.2-debug-apk` (в нём APK). Для этого предусмотрен файл `.github/workflows/build.yml`. Репозиторий может быть приватным.

## Как установить и проверить безопасно

1. Скопируйте APK на USB-флешку.
2. Подключите её к телевизору, найдите APK через файловый менеджер. Разрешите установку из этого источника, если система спросит.
3. Откройте **DEXP Lite** через список приложений. Сначала проверьте пульт, открытие 2–3 приложений, возврат из них и меню настроек.
4. **Не отключайте штатный лаунчер Яндекса.** Если Android предлагает выбрать Home, используйте сначала **«Только сейчас»**, а не «Всегда».
5. Чтобы удалить пробную оболочку, зайдите в **Настройки → Приложения → DEXP Lite → Удалить**. Если назначили её домашней, сначала очистите её действие по умолчанию (если меню доступно).

## Как диагностировать тормоза и очистить ненужное

**ADB может отсутствовать или быть отключён в некоторых версиях YaOS.** Не меняйте неизвестные настройки инженерного меню: ошибочная настройка панели может сделать телевизор непригодным к использованию. При отсутствии ADB не нужно взламывать загрузчик или прошивать другую систему.

1. На компьютере установите Android Platform Tools (`adb`) и Python 3.
2. Если отладка доступна и **включена самим владельцем телевизора**, узнайте IP телевизора, подключите компьютер и ТВ к одной локальной сети.
3. В папке `tools` выполните (пример IP замените на свой):

```bash
python tv_manager.py doctor --connect 192.168.1.50
python tv_manager.py review
```

`doctor` **ничего не меняет**, сохраняет локальный текстовый отчёт модели/сборки/памяти/пакетов. Перед отправкой отчёта кому-либо проверьте наличие личных данных. `review` показывает два осторожных кандидата на отключение, если они обнаружены.

**Только после проверки отчёта и если эти службы не нужны:**

```bash
python tv_manager.py disable --package com.yandex.android.advid
# Подтвердите действие словом ОТКЛЮЧИТЬ
```

Чтобы вернуть всё, что отключила эта утилита:

```bash
python tv_manager.py restore
```

Утилита использует `pm disable-user --user 0`, не трогает системный раздел и не разрешает отключение других пакетов. Встроенные приложения, связанные с входами HDMI, эфиром, обновлениями, сетью и системным меню, защищены от вмешательства.

**Если у вас только телевизор и флешка**, начните с установки лаунчера, не пытайтесь выполнять ADB-команды с самого ТВ. Очистку системных приложений можно настроить позднее после получения диагностического отчёта.

## Что сделать до запуска этой процедуры

- Проверьте свободное место во внутреннем накопителе.
- Удалите обычным способом приложения, которыми не пользуетесь.
- Измерьте реакцию пульта и запуск любимого приложения до/после установки DEXP Lite. Не ориентируйтесь лишь на впечатление.
