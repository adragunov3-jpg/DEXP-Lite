# Изменения

## 0.2.0
- Новая графитово-фиолетовая оболочка с большим баннером, часами и сеткой иконок.
- Два раздела: избранное и все приложения.
- Добавление и удаление избранного долгим нажатием OK.
- Запуск установленных Android TV / Android приложений.
- Отдельная безопасная утилита ADB для диагностики, осторожной чистки и отката.
- Конфигурация GitHub Actions для сборки APK из исходников.

## 0.1.0
- Простейшая сетка приложений, системные настройки.
